# Yiepie Space ✨

A cute Y2K friendship website for planning, memories, and fun with friends.

## Features 💕

- 📅 Calendar & Events
- 🎟️ Invitations with RSVP
- 👗 Outfit Planner
- 💬 Messages & Notes
- ⭐ Ratings
- 📸 Photo Gallery
- 🎵 Shared Playlist
- 📝 To-Do List
- 🎯 Bucket List
- 🤫 Anonymous Confessions

## How to Run 🚀

1. Download all files:
   - index.html
   - style.css
   - script.js

2. Put them in the same folder.

3. Open `index.html` in your browser.
